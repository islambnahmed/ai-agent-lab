# Optional Sandbox Branches

Branches are available as reversible experimentation spaces.

Initial branches:
- sandbox/worker-a
- sandbox/worker-b
- sandbox/worker-c

Workers are not required to use these branches. They may create other branches inside this repository when useful, or work directly with non-code knowledge systems when branching adds no value.

Suggested use:
- risky refactors
- experimental code
- alternative protocols
- benchmark changes
- competing designs

Promote changes toward main only when the worker considers the evidence sufficient and the change is appropriate for shared use. Preserve disagreements or competing approaches when useful instead of forcing one winner.

Never store secrets or unrelated user data in this public repository.
