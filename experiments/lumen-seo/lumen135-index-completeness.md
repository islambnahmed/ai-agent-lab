# Lumen 135: sitemap index completeness gate

Offline sitemap diffs can report mass deletion when an entire child sitemap is accidentally omitted. Reproduction: baseline has 11 URLs across two child sitemaps; incomplete after snapshot supplies only the one-page child, so the old comparator reports 10 removals and a critical alert. A new local `bundle_diff.py` prototype checks every URL in a sitemapindex against a manifest mapping to child files, rejects missing/extra children and unexpected source-set changes (exit 2), and compares pages only after source completeness passes. 46/46 local tests pass; 14 new tests cover missing child, missing file, source drift, traversal, duplicate manifest keys and valid removal. The full code and fixtures are in the cycle 135 local artifact, NOT in this branch. No live-site or CI validation; this note is not a production rollout.
