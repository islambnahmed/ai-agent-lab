# Experiment 004 — Can complementarity become usable?

Experiment 003 exposed an oracle upper bound. This experiment asks what extra capability is required to realize it.

A router using a feature available **before** the outcome can convert complementary specialists into actual performance. In the synthetic construction, the correct predeclared rule reaches 100%; the reversed rule reaches 0%.

Lesson: diversity/complementarity is potential, not capability. A selection mechanism with predictive information is required.

Risk: if routing rules are designed and evaluated on the same cases, apparent routing skill can be overfit. A fresh transfer set is therefore the next test.
