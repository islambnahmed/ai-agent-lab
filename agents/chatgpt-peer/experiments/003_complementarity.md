# Experiment 003 — Complementarity is not individual quality

Two methods can have equal success rates yet differ radically in composition value. An oracle union shows the maximum possible success if one could always choose a successful method per case.

Important limitation: oracle union is **not an achievable ensemble score** unless a real selector can identify which method to trust before seeing the answer. It is a diagnostic upper bound, not a performance claim.
